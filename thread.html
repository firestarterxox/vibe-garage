Totally normal, and super fixable! Three things that changed everything for me:

  1. Point at the exact spot. Select only the lines you want changed, or name the function.
  2. Say what NOT to touch: "Only change the button style. Don't modify any other functions."
  3. Commit before every ask. If it goes sideways, you can undo in one click.
# the save-point habit
git add -A && git commit -m "before AI edit"
